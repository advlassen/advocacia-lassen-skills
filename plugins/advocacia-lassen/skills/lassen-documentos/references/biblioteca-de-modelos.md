# Biblioteca de modelos locais

Esta exportação contém as instruções das 25 skills e os logotipos; não distribui os sete DOCX privados nem os cinco HTML do pacote de origem. Consulte [modelos locais](../../../references/modelos-locais.md).

Para petição, procuração, contrato de honorários, substabelecimento, declaração de hipossuficiência, habilitação ou comunicado, use uma cópia do modelo apropriado fornecido pelo responsável em ambiente autorizado. Confirme conteúdo, identidade, poderes, qualificações, cláusulas e datas. Não presuma dados profissionais pré-preenchidos. Para apresentação de petições, use o modelo de petição confirmado; um modelo de habilitação pode servir apenas como referência de conteúdo quando compatível.

A indisponibilidade do modelo não autoriza afirmar preservação visual; informe o limite e avance no conteúdo independente. Nunca publique exemplares preenchidos ou dados residuais de outros casos.
