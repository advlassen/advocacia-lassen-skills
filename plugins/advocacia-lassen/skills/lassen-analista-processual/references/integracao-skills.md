# Integração com as skills de área

O analista faz o diagnóstico; a peça se elabora na skill da área. Depois de identificar a matéria,
encaminhe o caso, entregando o Relatório Processual Estratégico como base pronta para a elaboração.

## Para onde encaminhar
- Matéria penal (crime, prisão, denúncia, execução penal) → `lassen-criminal`.
- Matéria cível (responsabilidade, contratos, consumidor, obrigações, direitos reais, cobrança) →
  `lassen-civil`.
- Relações familiares (divórcio, guarda, alimentos, partilha, inventário, sucessões) →
  `lassen-familia-sucessoes`.
- Relação de trabalho (verbas, vínculo, jornada, defesa da empresa) → `lassen-trabalhista`.
- Empresa (societário, contratos empresariais, compliance, LGPD, recuperação de crédito) →
  `lassen-empresarial`.
- Método geral, padrão de peça e .docx quando não houver skill de área específica →
  `sistema-juridico-lassen`.

## Como encaminhar
Diga qual a matéria predominante e quais as conexas (muitos casos cruzam áreas). Passe adiante o que
a skill de área precisa: a questão central, a melhor tese, os pontos fortes e fracos, a prova
disponível e a que falta, o risco e o próximo movimento. A peça lá começa da estratégia daqui, não do
zero.

Se o caso for só de análise (o cliente quer o diagnóstico, não a peça), a entrega termina no
relatório. Se as duas skills estiverem disponíveis, a passagem é direta; se não, o relatório já deixa
o caminho pronto para quando a skill de área for usada.
